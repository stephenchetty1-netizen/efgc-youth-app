# EFGC Scripture photograph sources

The Scripture Generator displays cropped, re-encoded photos from Pexels. Pexels permits use and modification in an app under its [license](https://www.pexels.com/license/). These are not supplied as unmodified stock-photo downloads. Each generated portrait is overlaid with the EFGC logo and the selected Scripture in the finished poster. Photos are fetched by `scripts/prepare-scripture-photos.py` during the GitHub Pages build and checked before release.
